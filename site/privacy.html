Privacy policy

Yarden Channels Board is a private tool used only by its owner, for the owner's own YouTube channels. Last updated: 5 November 2026.

YouTube API Services

This tool uses YouTube API Services. By using it you agree to the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy.

What is read

With read-only permission from the channel owner, the tool reads channel and video details, such as titles, thumbnails and publish times, and statistics, such as views, watch time and subscribers. It does not read data about individual viewers.

How it is used and stored

The data is used only to show the owner a private page. Once an hour an automated job on GitHub reads the data and stores it encrypted on GitHub Pages. It can only be opened with a key held in the owner's private link. A copy may also be kept on the owner's computer. The read-only permission is kept on the owner's computer and in encrypted GitHub Actions secrets, so the job can run. The tool does not sell or share this data with anyone. The tool's pages use no cookies and no advertising. Thumbnails load directly from YouTube's servers.

Keeping and deleting data

Data is refreshed about once an hour. Data that can no longer be refreshed is deleted within 30 days.

Withdrawing permission

Permission can be withdrawn at any time on the Google security settings page. Data from that channel is then deleted within 30 days.
